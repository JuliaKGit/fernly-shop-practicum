# Pipeline gates

| Risk | Gate | Kind | Where it lives | Proof |
| --- | --- | --- | --- | --- |
| The agent pushes or comments by itself | The job that runs the agent is not given a GitHub token, and its checkout does not keep the token in `.git/config`. A later job, with no agent, is the one that pushes and comments. | code: workflow | `.github/workflows/pr-triage.yml` | `workflow: agent jobs have no GitHub token`; `workflow: agent checkout persist-credentials false` |
| The agent changes app code, workflows or baselines | A patch is refused when it touches shop code, `.github`, a screenshot baseline, or `scripts/`, even if the allowed list would match that path. | code: guard | `scripts/agent-guard.sh` | `agent-guard: plan plus web/src blocked`; `agent-guard: workflow change blocked`; `agent-guard: screenshot baseline blocked`; `agent-guard: agent-guard.sh blocked with scripts/*` |
| The agent approves its own plan | The hook refuses merge, approve, and adding a label. The tests job runs only when a person adds `plan-approved`. | code: hook, code: workflow | `.cursor/hooks/guard-approvals.sh`; `.github/workflows/pr-triage.yml` (`tests` job `if`) | `hook approvals: deny approve`; `hook approvals: deny merge`; `hook approvals: deny label`; `workflow: tests job needs plan-approved by a person` |
| Text in the diff steers the agent | The diff, commit messages, pull request text, test output, and pages are data. Instructions in them are not followed. This gate lives only in a prompt. | prompt: a rule the agent reads | `.cursor/agents/change-triage.md`; `.cursor/skills/diff-to-test-plan/SKILL.md` | not proven |
| A secret leaks | The job that runs the agent is not given `GH_TOKEN` or `GITHUB_TOKEN`. The hook refuses `printenv`, a bare `env`, and reading `CURSOR_API_KEY`, `GH_TOKEN`, or `GITHUB_TOKEN`. | code: workflow, code: hook | `.github/workflows/pr-triage.yml`; `.cursor/hooks/guard-approvals.sh` | `workflow: agent jobs have no GitHub token`; `hook approvals: deny printenv` |
| A run burns money | Every pr-triage job has `timeout-minutes`, so a stuck job stops. The plan job also skips a push that did not change the shop and is not a replan. | code: workflow | `.github/workflows/pr-triage.yml` | `workflow: every pr-triage job has timeout-minutes`. The skip when the push changes nothing under test is not proven. |
| Code from a fork runs with my secrets | No workflow uses a `pull_request_target` trigger. The job that runs the agent checks the pull request out with `persist-credentials: false` and is not given a GitHub token. | code: workflow | `.github/workflows/`; `.github/workflows/pr-triage.yml` | `workflow: no pull_request_target trigger`; `workflow: agent checkout persist-credentials false`; `workflow: agent jobs have no GitHub token` |
| A baseline changes without review | The hook refuses Playwright `--update-snapshots` and `-u`. A patch that adds a `*-snapshots` file is refused. | code: hook, code: guard | `.cursor/hooks/guard-baselines.mjs`; `scripts/agent-guard.sh` | `hook baselines: deny update-snapshots`; `hook baselines: deny -u`; `agent-guard: screenshot baseline blocked` |
