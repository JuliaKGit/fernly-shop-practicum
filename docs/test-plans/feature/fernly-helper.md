# Test plan: Fernly Helper

Adds an **Ask Fernly** chat helper on every page. The customer types a request; `POST /api/helper/chat` returns a reply and optional tool call (`search_plants`, `open_plant`, `add_to_cart`, `care_tip`); the browser runs the tool. Behavior is defined in `docs/features/fernly-helper.md`. Cart and catalog side effects still follow `docs/PRODUCT.md`.
