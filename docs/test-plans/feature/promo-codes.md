# Test plan: feature/promo-codes

## Summary

Adds promo codes on the cart: `POST` / `DELETE /api/cart/promo`, `discount` and `promoCode` on cart and order schemas, a `PromoCodeInput` cart-summary slot, and a discount line in `OrderSummary` on cart, checkout, and order pages. Practice codes: `LEAFY10` (10% off plants), `FREESHIP` (free shipping), `SPRING5` (expired 30 Apr 2026).
