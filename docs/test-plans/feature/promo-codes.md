# Test plan: feature/promo-codes

## Summary

Adds promo codes to the cart: `POST` / `DELETE /api/cart/promo`, cart/order fields `discount` and `promoCode`, a `PromoCodeInput` slot on the cart, and discount lines in `OrderSummary` on cart, checkout, and order pages. Documented codes: `LEAFY10` (10% off plants), `FREESHIP` (free shipping), `SPRING5` (expired).
